# Lista de verificación manual: bloque carta

Ejecutar tras cada fase del [plan de bloques](PLAN_BLOQUES.md): `npm run dev` y revisar en el navegador.

- [ ] La app carga sin errores en la consola ni en el servidor.
- [ ] Se ve el sobre flotando sobre el fondo azul con partículas.
- [ ] Al pasar el mouse, la tapa del sobre se abre; al salir, se cierra.
- [ ] Clic en el sobre muestra el botón "Abrir Carta".
- [ ] Clic en "Abrir Carta" inicia la música en bucle.
- [ ] La carta sale del sobre y aparece el texto con efecto de máquina de escribir.
- [ ] El primer párrafo empieza con "Entre días ocupados..." (letra inicial completa).
- [ ] Se muestran el encabezado "Hola, Mari", el bloque de código y la firma "Con cariño...".
- [ ] Tras unos segundos aparecen los botones "Sí, acepto" y "No puedo...".
- [ ] El botón "No" se esquiva las 3 primeras veces que se le acerca el mouse.
- [ ] "Sí, acepto" muestra el mensaje de aceptación con confeti.
- [ ] "No puedo..." muestra el mensaje de rechazo y permite reconsiderar.
- [ ] `npm run build` termina sin errores.
